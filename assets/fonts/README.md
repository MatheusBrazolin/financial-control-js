# Fonte

`inter-variable-latin.woff2` — **Inter**, de Rasmus Andersson, subconjunto
latino da versão variável (48 KB).

Licenciada sob a SIL Open Font License 1.1: https://github.com/rsms/inter

Está hospedada aqui, e não no Google Fonts, por dois motivos: o app
continua funcionando offline, e nenhuma requisição do usuário sai para
um terceiro — o que combina com a promessa de que os dados não saem do
navegador.
